# Ascent Window icon pack

Selected identity direction for the AFM / Field Notes portfolio.

## Full-size masters

- `full/png/ascent-window-dark.png` - original selected raster on the portfolio navy background, 1254 x 1254.
- `full/png/ascent-window-transparent.png` - background-removed raster with clean transparency, 1254 x 1254.
- `full/svg/ascent-window-dark.svg` - editable vector reconstruction with the portfolio background.
- `full/svg/ascent-window-transparent.svg` - editable vector reconstruction without a background.

## Web-ready files

The `web/` folder includes:

- `favicon.ico`
- `favicon-16x16.png`
- `favicon-32x32.png`
- `apple-touch-icon.png`
- `android-chrome-192x192.png`
- `android-chrome-512x512.png`

Additional dark and transparent PNG sizes from 16 px through 512 px are in `favicon/`.

## Suggested HTML

```html
<link rel="icon" href="assets/icons/favicon.ico" sizes="any">
<link rel="icon" type="image/svg+xml" href="assets/icons/ascent-window-dark.svg">
<link rel="apple-touch-icon" href="assets/icons/apple-touch-icon.png">
```

## Palette

- Ink: `#060b18`
- Paper: `#eef4f1`
- Cyan: `#86e5e0`
- Amber: `#f4b860`

## Provenance

The source PNG was the user-selected generated Ascent Window concept. The transparent PNG was derived deterministically from that source. The SVG files are clean editable vector reconstructions of the selected geometry; they do not embed the raster image.
